# Engineering Mastery

 Тетрадь по программированию и компьютерным технологиям — личный конспект с проверенными примерами кода и объяснениями.
 Сборник практических руководств, примеров кода и теоретических материалов по Computer Science и разработке программного обеспечения.

## О проекте

Здесь систематически документируются:

- **Классические алгоритмы и структуры данных** — от сортировки до графов
- **Языки программирования** — Go, Python, Rust и другие (с акцентом на практическое применение)
- **Сетевые протоколы и API** — HTTP, gRPC, WebSocket
- **Базы данных** — SQL, NoSQL, схемы проектирования
- **Системное проектирование** — микросервисы, распределённые системы, DevOps
- **Паттерны проектирования** — GoF, архитектурные паттерны

Каждая тема представлена как самодостаточный модуль с:
- Кратким теоретическим введением;
- Рабочими примерами кода, которые можно запустить локально;
- Ссылками на дополнительные ресурсы;

## Темы

- [Protocol Buffers (protobuf)](./protobuf/README.md) — сериализация данных для API и хранения

## Как использовать

1. Выбери интересующую тему из списка.
2. Прочитай `README.md` для понимания основ.
3. Запусти примеры в папке `examples/`.
4. По мере необходимости — углубляйся в ссылки.
