# Singleflight

## Задача

Представь, что мы пишем прокси-сервис для ресурсоемкого API (или тяжелой БД). Сервис принимает запросы по строковому ключу.

### Условия

- Несколько клиентов могут одновременно запросить данные по одному и тому же ключу.
- Если запрос по ключу `X` уже выполняется в данный момент — мы не запускаем повторный запрос.
- Новые клиенты ждут завершения первого и получают тот же самый результат.
- Как только оригинальный запрос завершился — ключ снова считается свободным.
- Следующий (новый) запрос по нему должен честно пойти в API/БД заново.
- Запросы по разным ключам друг друга блокировать не должны.

## Реализация

Нужно реализовать механизм `singleflight` — паттерн, при котором одновременно выполняется только один запрос по уникальному ключу. Остальные запросы по тому же ключу ждут результата первого.
